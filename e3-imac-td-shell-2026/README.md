# E3 IMAC - TD shell - 2026

Dépôt contenant les exercices du cours d'introduction à la ligne de commande

## Organisation

Le dépot contient des fichiers correspondant aux différents exercices, classés par atelier et par question.

## Principe

1. Cloner le dépôt sur votre propre compte github (ou sur une autre forge).
2. Modifier les fichiers pour y apporter vos réponses.
3. Effectuer des demandes de fusion auprès de vos camarades pour comparer et fusionner vos réponses et garder les meilleures.
4. En fin de journée, faire une demande de fusion dans le dépot d'origine (https://github.com/aboutofpluto/e3-imac-td-shell-2026) qui contiendra donc la correction ultime !

_Suggestion_ : vous pouvez vous mettre par groupes de 2 sur chaque dépôt afin de créer et manipuler des branches.

## Indications complémentaires

Par soucis de simplification et d'uniformité, la ligne de commande à utiliser pour les exercices est `bash` : https://www.gnu.org/software/bash/

Le format des fichiers indiquent le type de contenu :
- les fichiers `.cmd` doivent contenir la commande qui constitue la réponse à la question (précédée d'un `$`)
- les fichiers `.txt` doivent contenir du texte, une explication simple de la/les solution(s)/réponse(s).
- les fichiers `.sh` sont des scripts qui devront pouvoir être exécutés.

Pour exemple : `atelier-1/exo-1.cmd`, `atelier-1/exo-8.txt` ou `atelier-3/exo-3.sh`

_Note_ : le format `.cmd` n'est pas standard, il n'est utile que pour cet atelier et pour le différencier.
